# Agentic-AI-Workshop-for-Engineered-Systems-with-MATLAB-and-Simulink

## Agenda
Engineered systems are becoming more complex, more software-defined, and more dependent on rapid iteration across requirements, models, simulations, tests, and deployment artifacts. Agentic AI offers a practical way to accelerate this work by helping engineers reason across these connected artifacts, automate repetitive tasks, and keep human expertise focused on design decisions, validation, and system-level tradeoffs.

In this hands-on workshop, you will see how “engineers-in-the-loop” agentic workflows can accelerate exploration, automation, and verification across MATLAB® and Simulink® while still keeping design intent, traceability, and decisions under your control. Get firsthand experience performing agentic AI workflows with MATLAB and Simulink. Highlights include:

- Connecting an AI agent to MATLAB and Simulink using the Model Context Protocol (MCP)
- Utilizing MATLAB Agentic Toolkit to automatically create, edit, and understand MATLAB algorithms
- Leveraging Simulink Agentic Toolkit to explore, modify, and debug Simulink architectures

## Tools required
- MATLAB R2023a or beyond 
- Coding Agent (Codex Gemini, GitHub Copilot, etc.)
- [MATLAB Agentic Toolkit] (https://github.com/matlab/matlab-agentic-toolkit)
- [Simulink Agentic Toolkit](https://github.com/matlab/simulink-agentic-toolkit)
